How it was made

No video model drew this film. Claude Opus 5.5, working in Claude Code, wrote each set, the character animation, the camera moves, the edit and the score as code, and the code rendered them to video.

The same approach is packaged as Lemo-Opuscar: 43 film styles, each a style prompt plus a demo film, installable as a Claude Code skill so your agent can direct a film about your own topic.
